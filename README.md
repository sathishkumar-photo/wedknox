# Wedknox Photography website
1. Install Node.js (LTS) from nodejs.org. Needs internet for Google Fonts.
2. In this folder run: `npm install` then `npm run dev`, open http://localhost:3000
3. Edit `config/site.ts` to change phone, packages, photos, films, reviews, social links.
4. Put photos in public/media/photos, videos in public/media/videos, logo in public/media/brand.
5. Deploy: push to GitHub, import on vercel.com, click Deploy.
